The single line I would send my younger self if one line were all I got:

> Stop trying to be the smartest person in the room, kid — be the one who finishes things instead.

## How to run

```sh
python3 main.py
```

This writes the line to `/output/entry.txt` (creating `/output` if needed).
Python standard library only — no third-party dependencies, no network.
